# 轨迹记 UI 设计提示词（摹客 / 小摹 AI 版）

> 用法：在摹客的小摹 AI 里，**一次生成一个页面**效果最好。
> 每次把【通用背景】+ 对应页面那一段一起粘进去。

---

## 通用背景（每次都带上）

```
请为一款 Android 手机 App 设计高保真 UI 界面。

App 名称：轨迹记
用途：一款 GPS 运动轨迹记录工具。用户点击开始后，App 在地图上实时画出
行走/骑行/跑步的路线，并统计总距离和时长，可以保存并回看历史轨迹。
目标用户：日常跑步、骑行、徒步的普通用户。

设计风格：现代、简洁、清爽，有运动感；遵循 Material Design 3；浅色主题；
主色用青绿色（约 #009688）体现运动感；大量留白；卡片圆角 16px、柔和阴影；
重点数据（距离、时长）要大而醒目。
设备：主流 Android 手机竖屏，1080 x 2340。
界面文字：简体中文。
字号建议：页面标题 20sp，重点数字 28~32sp，正文 14~16sp，次要信息 12sp。
```

---

## 页面一：地图主页（最重要，出两种状态）

```
设计「地图主页」：
- 整个屏幕是一张地图（用占位地图示意）。
- 顶部：App 名称"轨迹记"；右上角一个"历史记录"图标入口。
- 地图顶部浮一个半透明信息卡片，突出显示两项数据：
  距离（如 1.85 公里）、时长（如 00:12:35），数字大而清晰。
- 底部中央：一个醒目的主按钮"开始记录"；记录进行中时变为"停止记录"，
  按钮变红色，并有"正在记录"的视觉提示。
- 右下角：一个较小的圆形"回到当前位置"定位按钮。
- 请分别出"未开始记录"和"正在记录"两种状态的效果图。
```

---

## 页面二：历史记录列表

```
设计「历史记录列表页」：
- 顶部标题"历史记录"，带返回按钮。
- 用卡片列表展示每一条已保存轨迹，每个卡片显示：
  距离（公里）、时长、记录日期时间（如 2026-10-20 15:30）。
- 卡片要有可点击的层次感，点击进入详情。
- 每个卡片可带一个小的运动图标或轨迹缩略图（可选）。
- 另外出一个"暂无记录"的空状态页面。
```

---

## 页面三：轨迹详情

```
设计「轨迹详情页」：
- 顶部标题"轨迹详情"，带返回按钮。
- 主体是一张地图，上面用一条明显的彩色线画出完整轨迹路线，
  起点和终点各有一个标记。
- 地图上浮一个统计卡片，显示：距离、时长、记录时间。
- 风格与主页保持一致。
```

---

## 交付要求（可加在末尾）

```
请保持三个页面设计风格统一（颜色、间距、字体、组件一致）。
如果可以，请标注主要颜色色值和字号，方便后续用代码还原。
风格可参考 Keep / 悦跑圈 / Strava 的精致度：地图干净、数据醒目、界面简洁。
```
